# CDK 福利自动领取 - 油猴脚本

> 自动扫描 linux.do 站内 CDK 链接，倒计时提醒，自动跳转并点击领取

## 功能特性

- **自动扫描** - 每60秒自动扫描 linux.do 站内 CDK 链接（搜索API + 福利板块）
- **倒计时提醒** - 实时倒计时显示，支持自定义提前跳转时间
- **自动领取** - 跳转到 CDK 页面后自动点击「立即领取」按钮
- **时间排序** - 支持按CDK时间、发帖时间、发现时间排序
- **帖子跳转** - 扫描结果可直接点击查看原始帖子
- **控制台日志** - 内置调试控制台，支持过滤、导出日志
- **停止/恢复扫描** - 可随时暂停和恢复自动扫描
- **版本显示** - 面板内实时显示当前脚本版本
- **右侧面板** - 可收起的右侧面板，不遮挡主要内容

## 安装方式

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击 [安装脚本](https://github.com/Aixgeekx/Linux-do-CDK-/raw/main/cdk-auto-claim.user.js)
3. 或手动复制脚本代码到 Tampermonkey 新建脚本中

## 使用说明

### 基本使用
- 访问 linux.do 后，右侧会出现绿色触发条
- 鼠标悬停或点击触发条打开控制面板
- 脚本会自动扫描并显示发现的 CDK 链接

### 扫描结果
- 发现新 CDK 后会显示在「扫描结果」标签页
- 每个结果显示 CDK 时间、发帖时间
- 支持多种排序方式（CDK时间/发帖时间/发现时间）
- 点击「查看帖子」可跳转到原始帖子
- 点击「一键添加」将 CDK 添加到提醒列表
- 可随时「停止扫描」或「恢复扫描」

### 提醒列表
- 添加的 CDK 会显示在「我的提醒」标签页
- 实时倒计时显示距离开始时间
- 支持自动跳转功能（默认提前5秒）
- 可手动删除不需要的提醒

### 控制台
- 「控制台」标签页显示完整的扫描日志
- 支持按关键词过滤日志
- 支持导出日志为 txt 文件
- 可清空日志记录

### 手动添加
- 支持手动输入 CDK 名称、地址和开始时间
- 时间格式：`2025/10/22 17:00:00`

## 扫描来源

脚本从以下来源扫描 CDK：
1. **搜索API** - `linux.do/search.json?q=cdk`
2. **福利板块** - `/c/welfare/36`、`/c/welfare/welfare-lv2/61`、`/c/welfare/welfare-lv1/60`
3. **当前页面** - 当前浏览页面中的 CDK 链接

## 注意事项

- hCaptcha 验证需要手动完成，脚本无法自动绕过
- 弹窗拦截可能影响自动跳转功能，请允许 linux.do 的弹窗
- 脚本使用 Discourse API 获取数据，需要登录状态
